# Maintaining the diagrams

Both SVG architecture diagrams are editable vector graphics with embedded text. Edit them in Inkscape, Figma or any text/SVG editor. A PNG preview is also supplied for applications that do not render SVG. The screenshots in `../screenshots/` are original-source evidence and must not be modified to suggest configurations or outcomes that were not observed.

When modifying the topology, consult `../docs/architecture.md` and the underlying internship report before changing any network interface, asset role or data flow.
